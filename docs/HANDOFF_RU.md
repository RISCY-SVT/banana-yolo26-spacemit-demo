# Передача исполнителя YOLO26 K1X INT8 0.9.2

## Назначение

Это самостоятельный точный исполнитель полного графа YOLO26n-640 для платы
Banana-Pi BPI-F3 с процессором SpacemiT K1X. Исполнитель использует целочисленный
контракт `K1X_INT8_V1` и возвращает тензор `1x300x6`. В измеряемом пути нет
ONNX Runtime, Python, файлового ввода-вывода на каждый запуск, вещественного
Q/DQ и динамической диспетчеризации графа.

Статус передачи: **готов к инженерному использованию как оптимизированный
эталон; производственная сертификация не проводилась**.

## Точная область поддержки

| Параметр | Значение |
|---|---|
| Плата | Banana-Pi BPI-F3 / SpacemiT K1X |
| Модель | `manual_e2e_rep_conv_matmul_qdq.onnx` |
| SHA-256 модели | `30a94e4738606673b5e0a73499cbc977167f046f8fa8637d6040ce744f429c0c` |
| Профиль графа | `K1X_INT8_V1_YOLO26N_640_FULL_GRAPH_001` |
| SHA-256 манифеста пакета | `fab4a72cf524ce0a205ceca0384144f2eee7bc79dff3f4db8b7208614e8407be` |
| Вход | float32 NCHW `1x3x640x640` в `[0,1]` или RGB8 640x640 |
| Выход | 300 строк `[x1,y1,x2,y2,score,class]` типа float32 |

Другие модели, размеры, платы, раскладки и числовые контракты не поддерживаются.
Подготовка letterbox остается обязанностью вызывающей стороны, кроме режима CLI
с изображением и сборкой с OpenCV.

## Схема данных

```text
float32 NCHW или RGB8
        |
        v
точное RNE-квантование / компактный RGB stem
        |
        v
арена NCHWc8 -> плотные IME + RVV E2c5 -> depthwise / LUT / concat
        |                                      |
        +------- attention model10/22 ---------+
        |
        v
редукция head без промежуточной копии -> стабильный top-300 -> 1x300x6

CPU0-3: IME-воркеры   CPU4: контроллер   CPU5-7: только системная нагрузка
```

## Быстрый запуск

```bash
RELEASE=/data/releases/banana-yolo26-k1x-int8-executor/0.9.2-stage59-final-runtime
PACKAGE=$RELEASE/package

$RELEASE/bin/y26_k1x_healthcheck \
  "$PACKAGE" \
  fab4a72cf524ce0a205ceca0384144f2eee7bc79dff3f4db8b7208614e8407be \
  "$RELEASE/fixtures/bus_640_nchw_f32.bin" \
  0xd43f5e018b415631

taskset -c 0-4 $RELEASE/bin/yolo26_k1x_int8 \
  --package "$PACKAGE" \
  --image "$RELEASE/fixtures/bus_640_nchw_f32.bin" \
  --input-mode preprocessed-f32 \
  --profile compatibility \
  --expected-manifest-sha256 \
    fab4a72cf524ce0a205ceca0384144f2eee7bc79dff3f4db8b7208614e8407be \
  --verify-known-fixture --expected-output-hash 0xd43f5e018b415631 \
  --verify-determinism --output-json /data/y26-output.json
```

Профиль выделенной платы:

```bash
$RELEASE/scripts/o2-system-profile.sh run -- \
  taskset -c 0-4 $RELEASE/bin/yolo26_k1x_int8 \
  --package "$PACKAGE" --image "$RELEASE/fixtures/bus_640_nchw_f32.bin" \
  --input-mode preprocessed-f32 --profile low-latency-dedicated \
  --expected-manifest-sha256 fab4a72cf524ce0a205ceca0384144f2eee7bc79dff3f4db8b7208614e8407be \
  --output-json /data/y26-output.json
```

Обертка O2 восстанавливает состояние после штатного завершения, ошибки,
тайм-аута и сигналов `INT`, `TERM`, `HUP`. После `SIGKILL` выполните
`o2-system-profile.sh restore-stale`.

## Профили

| Профиль | Ожидание воркеров | Система | Назначение |
|---|---|---|---|
| compatibility | condition variable | исходное состояние | интеграция и совместная плата |
| low-latency | frame-gated spin | исходное состояние | выделенный процесс |
| low-latency-dedicated | frame-gated spin | обратимый O2 | измеренный режим выделенной платы |

Переменные окружения с номерами этапов не нужны. Выбор точных операторов встроен
в релизный профиль.

## Интеграция

Используйте один подготовленный дескриптор на один последовательный поток кадров.
Разные дескрипторы могут работать независимо; одновременный вызов одного
дескриптора возвращает `Y26_STATUS_BUSY`. Полный пример находится в
`examples/c_api_consumer.c`, а порядок вызовов описан в `INTEGRATION_GUIDE.md`.

## Доказанные свойства

- точное совпадение всех 215 целочисленных границ, F0-F7, bus и Zidane;
- COCO val2017: 5000/5000, mAP50-95 `0.3707408944391919`;
- IME только на CPU0-3, счетчик IME на CPU4-7 равен нулю;
- восстановление FRM, `vcsr`, `vxrm`, `vxsat`;
- проверка известного выхода: `0xd43f5e018b415631`.

Числа чистого исполнения, реального набора, RGB-входа, последовательного
конвейера и двухбуферной пропускной способности приведены отдельно в
`PERFORMANCE_AND_ACCURACY.md`. Их нельзя объединять в одну статистическую строку.

## Состав релиза

| Путь | Содержимое |
|---|---|
| `bin/` | консольная программа и проверка работоспособности |
| `lib/`, `include/` | библиотеки ABI1, метаданные CMake/pkg-config и открытый C-заголовок |
| `package/`, `fixtures/` | неизменяемый пакет полного графа и известный точный вход |
| `config/`, `scripts/` | безопасная конфигурация и сценарии сборки, запуска и O2 |
| `docs/`, `examples/` | руководства и компилируемый пример на C |
| `licenses/`, `sbom/` | уведомления и машиночитаемый перечень компонентов |
| `outputs/` | итоги известного примера, COCO и раздельных измерений |

Файлы `release_manifest.json`, `release_sha256.txt` и `SHA256SUMS` описывают и
проверяют все дерево. Исследовательские варианты и переменные окружения этапов в
основной каталог передачи не входят.

## Эксплуатационные ограничения

- Все файлы, пакеты и журналы должны находиться на NVMe `/data`.
- CPU4 является контроллером. CPU5-7 не должны выполнять IME.
- Исходный профиль загрузки сохраняется. O2 не меняет постоянно boot-параметры,
  sysctl, THP, частоту, хранилище и политику реального времени.
- Перед подготовкой проверяйте ожидаемый SHA-256 манифеста.
- Один дескриптор нельзя использовать одновременно из нескольких потоков.

## Удаление

```bash
$RELEASE/scripts/o2-system-profile.sh restore-stale
rm -rf -- "$RELEASE"
```

Релиз не устанавливает файлы в `/usr`, поэтому удаление версии не затрагивает
другие компоненты.

## Что не заявляется

Это не заявление о 20 FPS, не сервис камеры, не плагин поставщика и не
производственная сертификация. Stage58 является обслуживанием замороженного графа. Q31, другая
модель, обучение, student-модель и co-design требуют отдельной ветки, проекта и
разрешения.
