# Branch, Tag, and Freeze Guide

| Reference | Meaning |
|---|---|
| `v0.9.3-r640` | immutable stable R640 scheduler-maintenance release |
| `stage61-q0-final` | immutable Stage61 exact N-tail and R768 Q0 evidence |
| `v0.10.0-internal-rd.1` | integrated multiprofile internal-R&D source and SDK |
| `yolo26-custom-int8-engine` | final consolidated maintenance/evidence branch |

R640 remains default. Research branches remain available and are not deleted.
The consolidated line is frozen for correctness, compatibility, security,
documentation, and release maintenance. PTQ, training, QAT, model changes, or
co-design require a new branch/project and explicit authorization.
