# Архив поставки

Поставка Stage58 выпускается в двух детерминированных архивах:

```text
banana-yolo26-k1x-int8-executor-0.9.1-riscv64.tar.gz
banana-yolo26-k1x-int8-executor-0.9.1-riscv64.zip
```

Распакуйте архив на NVMe-раздел `/data` платы и проверьте его из корня:

```bash
sha256sum -c SHA256SUMS
export LD_LIBRARY_PATH="$PWD/lib:$PWD/opencv/lib"
bin/y26_k1x_healthcheck --build-info
```

В архив входят динамическая и статическая библиотеки исполнителя, заголовок
ABI1, метаданные CMake и pkg-config, проверочная программа и CLI, демонстрация
для камеры/изображения/видео, метки COCO, неизменяемый подготовленный каталог
`package/`, контрольный вход, скрипты, примеры, документация, минимальный набор
OpenCV 4.13 для демонстрации, лицензии, SBOM и отобранные результаты.

Сами библиотеки исполнителя от OpenCV не зависят. OpenCV нужен только программе
`y26_k1x_demo`. Исходный ONNX намеренно не включен: происхождение и право на
распространение обученных весов недостаточно подтверждены для этой поставки.
Файл `model/MODEL_SOURCE_NOT_REDISTRIBUTED.md` содержит SHA-256 и сведения для
воспроизведения. Подготовленная исполняемая модель `package/` включена всегда.

В архиве нет абсолютных путей и выходящих наружу символьных ссылок. Проверка
после чистой распаковки не использует пути дерева сборки. Все рабочие файлы,
журналы, снимки и видео следует хранить на `/data`; eMMC не выбран.
