# Stage61 Final Report

Classification: `stage61-attention-pareto-repaired-r768-q0-complete`.

Stage61 is bounded research on branch
`yolo26-k1x-attention-ntail-r768-q0`, based on Stage60 commit
`43c02b7051ddde9921a5348e4b4e8986b941212d`. It does not modify the accepted
0.9.3 maintenance branch, frozen release, integer contract, learned weights,
qparams, or public default profile. PTQ, Q1, training, and model-executor
co-design were not performed.

## Baseline And Scheduler Inheritance

The eight Stage60 Q0 package/profile identities were reproduced before the
attention change. Fixed outputs, all 215 boundaries, FRM/vector-CSR
restoration, affinity, and CPU4-7 IME-zero checks passed. Same-session ABBA is
the performance authority where the earlier scalar-cliff rows showed system
drift.

The Stage60 research head contains the two scheduler liveness repairs released
separately as 0.9.3. Host native, ASan/UBSan, and TSan suites pass; repeated
startup tests cover 8,000 workspaces and 20,000 readiness publications, and
repeated lifecycle tests cover 40,000 begin/end transitions. A board 2,000
transition smoke passes. Unsupported partial-worker completion is fail-closed.

The 312-case independent property matrix covers N=1..31 and the required
boundaries through 577, M/K tails, asymmetric zero points, INT8 extremes, RNE
ties, saturation, red zones, invalid sizes, and alias rejection. Python
arbitrary precision, portable scalar, board scalar, and board IME live outputs

All nine graph profiles then pass 99 profile/fixture combinations (F0-F7,
bus, canonical, and Zidane), with all 215 integer boundaries exact on every
combination. Selected route counters report zero scalar attention MatMul
fallbacks and zero CPU4-7 IME operations.

The host portable input oracle required one append-only correction: its
non-RVV fallback had widened to double before multiplying by 255, unlike the
frozen RVV float32/RNE input contract. F6/F7 now match fresh board scalar and
optimized dumps. The RISC-V object, selected arithmetic disassembly, package,
COCO outputs, and board runtime were unchanged.
