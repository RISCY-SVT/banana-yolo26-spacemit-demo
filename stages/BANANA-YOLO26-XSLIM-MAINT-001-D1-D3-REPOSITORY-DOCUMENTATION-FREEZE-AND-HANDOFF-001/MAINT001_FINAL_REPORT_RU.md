# Итог MAINT-001

Локальное техническое закрытие D1-D3 завершено. Пример реконструкции теперь
исполняемый и проверяемый; метаданные Python согласованы с принятой средой;
документация отделяет синтаксические проверки от синтетического выполнения и
от запрещённых здесь PTQ-сценариев. См. D1_D3_VERIFICATION.md.

XSlim: три локальных коммита D1/D2/D3, версия 2.1.2+riscy.2.1. Banana: только
новая папка стадии и указатель README. Финальные commit/tree receipts находятся
внешне к коммиту, в пакете/сыром корне: это исключает самоссылочный хеш.
Удалённая публикация: not-attempted-not-authorized. Старые теги и релизы
не перемещались; новые не создавались.

Проверки: 218 pytest + 65 subtests, финальный узкий прогон 26 + 2 subtests,
28 Banana tests, Ruff, compileall, bash/ShellCheck, strict mypy трёх изменённых
Python-файлов. Два раздельных wheel/sdist install/import/help/config/synthetic/
pip-check/uninstall проходят с заранее сохранённой принятой зависимой средой.
Это не проверка скачивания всех зависимостей из сети.

Все 117 runtime Python-модулей wheel и Requires-Dist совпадают с riscy.2.
Все восемь финальных артефактов двух сборок побайтово совпадают. Исходные
ненормализованные sdist различаются и сохранены; отличие не скрыто.

Научные результаты не менялись, B2/C2 не генерировались. Существующий C2 waiver
и исторический universal FAIL сохранены. CE, /data/ncnn, материализованный
ncnn и защищённые ветки проверяются before/after. Плата не использовалась.

Ограничения: не предоставлены аудиторские вложения, четыре внешних чата,
проверенная политика синхронизации рекомендуемого handoff-каталога и вторая
резервная площадка. Полная пятисторонняя передача знаний не заявляется.
Остаточные mypy/REUSE и внешние ссылки: remaining_debts.md. Новых научных
экспериментов для этого обслуживания не требуется.
