# Thermal Capture Known Debt

This append-only note does not alter the original Stage65C-R1 classification.

The zero-byte `thermal_before.tsv` and `thermal_after.tsv` files under some
full-val raw roots contain no thermal observations and must not support a
performance, throttling, or frequency claim. Stage65C-R1 did not open a
performance decision surface.

Future capture must enumerate readable thermal-zone files explicitly and
record both the source path and value. Empty capture output is a failed
instrumentation surface, not evidence of a stable temperature.
