# Local-setting gaps and disposition

The baseline gaps were exact tensor selection, deterministic conflict
handling, post-fusion root identity, survival through block-wise calibration,
and final exported-qparam evidence.

DEV-001A addresses those bounded gaps with exact or bounded-subgraph
selection, deterministic root assignment, strict no-match/ambiguity errors,
constrained observer results, optional qparam locking, and a final manifest.
The implementation does not productize the R3 graph localizer, implement
mixed precision, alter model topology, or claim runtime placement.

The B2 dry-run trace and no-override graph comparison remain separate hard
gates and are recorded in `existing_local_setting_b2_trace.tsv` and
`no_override_neutrality.tsv` after generation.
