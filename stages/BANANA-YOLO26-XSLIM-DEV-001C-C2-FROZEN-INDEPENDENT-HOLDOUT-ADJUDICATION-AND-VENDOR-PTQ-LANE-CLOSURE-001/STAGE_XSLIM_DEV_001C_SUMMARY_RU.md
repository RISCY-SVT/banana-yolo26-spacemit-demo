# XSLIM-DEV-001C: краткое резюме

Классификация:

```text
xslim-dev-001c-frozen-c2-independent-holdout-pass-
full-val-pareto-fail-vendor-ptq-lane-closed
```

Точный замороженный C2 проверен на новой естественной выборке из 5 000 ранее не использованных изображений COCO train2017. Пересечений с калибровочными, reconstruction, H500 и val2017 поверхностями нет по image ID, SHA-256 исходного JPEG и SHA-256 декодированных RGB-пикселей.

На H5000 C2 прошёл все заранее заданные условия: mAP `0.434699252` против `0.423400181` у B2, разница `+0.011299070`, `P(delta>0)=1.0`. Неопределённость AR-small устранена: разница `+0.000108655`, вероятность non-inferiority `1.0`. C2 также превысил A1 по mAP и AR-large, поэтому был открыт условный полный val2017.

На val2017 C2 прошёл весь universal gate против B2: mAP `0.378508778`, разница `+0.012649549`, нижняя граница 95% CI `+0.011938434`; ограничения AP/AR по размерам также выполнены. Однако Pareto repair против A1 не выполнен: прирост AR-large составил только `+0.001120178` при требовании `+0.002`, а `P(улучшение>0)=0.876` при требовании `0.95`.

Итог: C2 не допускается к отдельному K1X gate, B2 остаётся универсальным vendor-контролем, A1 остаётся неповышенным исследовательским артефактом. Ветка all-S8 PTQ для YOLO26 закрыта. Новые модели, qparams, XSlim source changes, board-команды и публикации не выполнялись.
