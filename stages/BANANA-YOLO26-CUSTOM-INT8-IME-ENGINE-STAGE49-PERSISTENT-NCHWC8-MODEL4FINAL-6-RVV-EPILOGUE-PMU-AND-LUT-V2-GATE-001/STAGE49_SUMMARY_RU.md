# Краткий итог Stage 49

Классификация: `stage49-persistent-nchwc8-slice-net-positive`.

Контракт `K1X_INT8_V1` и пакет для среза model4-final -> model6 проверены точно: Python, C++ scalar, scalar на плате и IME на плате совпадают по всем 17 границам для F0-F7. Выбран путь M12xN16/P3/E1, четыре рабочих ядра CPU0-3; управляющий поток закреплен за CPU4 без выполнения IME.

Model5: 5145.442776 мкс, p95 7663.699800 мкс. Внутренний постоянный NCHWc8-срез: 26710.414338 мкс против 42036.659040 мкс у диагностического B120 ORT, то есть на 36.459236% быстрее. Внутренних преобразований layout и float Q/DQ нет.

Внешние scalar-адаптеры остаются дорогими, точный RVV Q62 epilogue не реализован из-за отсутствия доказанного векторного 64x64->128 пути. Это не production/full-model результат. Следующий этап: ограниченное расширение persistent NCHWc8 до model8 и LUT-v2; student 416/512 остаются отложенными.
