# License And Code Reuse Plan

Default policy:

```text
learn, do not copy
```

No source code is copied from csi-nn2, ncnn, IREE, llama.cpp, vendor demos, or
closed binary artifacts in Stage 0.

If a later stage proposes copying source, require:

- license compatibility
- file attribution
- copied file list
- reason for copying
- review requirement

Closed vendor binaries must not be redistributed. When allowed, only
metadata/hashes/symbol lists/short strings/disassembly excerpts may be recorded.
