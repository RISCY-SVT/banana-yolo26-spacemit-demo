# Stage65B: краткое резюме

Классификация: `stage65b-blocked-independent-calibration-corpus-missing`.

Консолидация веток XSlim завершена без переписывания истории. Создана одна
долгоживущая ветка `riscy/k1x-yolo26`, опубликован архивный evidence-тег,
на GitHub и GitLab настроена защита, пять избыточных удалённых веток удалены
только после проверки достижимости коммитов.

Исследование точности остановлено на Gate 3. Единственный большой локальный
набор калибровки содержит 2015 изображений, и все 2015 побайтно совпадают с
COCO val2017. Независимый остаток равен нулю. Малые проектные наборы дают лишь
13 уникальных изображений вне val2017; это тестовые/синтетические/производные
фикстуры, а не лицензированный независимый detection-корпус.

PTQ, Graphwise, анализ границ пирамиды, гибридные абляции и COCO в Stage65B
не запускались. Плата K1X не использовалась. Для продолжения нужен существующий
лицензированный корпус минимум из 1000 различных изображений с доказанным
нулевым пересечением по SHA-256 с val2017; для size-balanced C500 нужны
аннотации. Stage65C не готов.
