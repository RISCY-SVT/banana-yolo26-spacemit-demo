# Разрешение модели и размер объектов

## Фиксированный вход

Исполнитель принимает только RGB-тензор 640x640. Камера может выдавать другое
поддерживаемое разрешение, но демонстрационная программа сохраняет пропорции,
уменьшает или увеличивает кадр и дополняет его до 640x640 значением 114.

## Данные COCO

В Stage58 принятые предсказания сопоставлялись с разметкой COCO val2017 без
`crowd`: одинаковый класс, уверенность не ниже 0,25 и IoU не ниже 0,50. Это
диагностический диапазон полноты, а не COCO AP и не гарантия для эксплуатации.

| Группа объектов | Объектов в разметке | Полнота |
|---|---:|---:|
| Малые COCO, площадь меньше 32² | 15 264 | 0,1794 |
| Средние COCO, от 32² до 96² | 12 392 | 0,5082 |
| Крупные COCO, не меньше 96² | 8 679 | 0,7991 |

После точного преобразования в 640x640 полнота по меньшей стороне объекта
составила: 0,0302 для 0-8 пикселей; 0,1141 для 8-12; 0,1882 для 12-16; 0,2458
для 16-24; 0,2988 для 24-32; 0,3921 для 32-48; 0,4872 для 48-64; 0,5717 для
64-96; 0,7685 для 96 пикселей и более. Полные выборки приведены в
`resolution_coco_bins.tsv`.

Первый измеренный диапазон с полнотой выше 50% — 64-96 пикселей по меньшей
стороне. Это наблюдение для конкретного набора данных, порога и правила
сопоставления, а не универсальный минимальный надежный размер.

## Ограничение реальной камеры

Единого минимального числа пикселей для всех объектов не существует. Результат
зависит от класса, контраста, смаза, перекрытия, объектива, расстояния, порога
уверенности и числа пикселей после преобразования в 640x640. Камера Stage58 была
направлена на неподвижный настенный плакат. В трех выбранных прогонах получено
132 принятых наблюдения класса `person`; минимальная меньшая сторона рамки
составила 348,886719 пикселя, и все наблюдения попали в диапазон `>=96`. Это
повторные результаты детектора без независимой разметки, измеренного расстояния
и смены сцены, поэтому они не задают порог надежности. Запрошенное исследование
трех сцен и пяти классов невозможно выполнить дистанционно; ограниченные данные
сохранены в `resolution_camera_observations.tsv`, а недоступные сцены и классы
не имитировались.
