# Карточка модели YOLO26n K1X INT8

## Поддерживаемый артефакт

Выпуск исполняет один подготовленный пакет:

| Поле | Значение |
|---|---|
| Семейство | детектор YOLO26n end-to-end |
| Контракт исполнителя | `K1X_INT8_V1` |
| Профиль полного графа | `K1X_INT8_V1_YOLO26N_640_FULL_GRAPH_001` |
| SHA-256 исходной модели | `30a94e4738606673b5e0a73499cbc977167f046f8fa8637d6040ce744f429c0c` |
| SHA-256 манифеста пакета | `fab4a72cf524ce0a205ceca0384144f2eee7bc79dff3f4db8b7208614e8407be` |
| Вход | RGB, фиксированный letterbox `640x640` |
| Выход | 300 строк float: `x1,y1,x2,y2,confidence,class` |
| Классы | COCO80 |

Каталог `package/` является полной подготовленной моделью времени выполнения.
Исполнитель не разбирает ONNX во время запуска и не использует ONNX Runtime.

## Точность

Принятый прогон COCO val2017 завершил 5000 из 5000 изображений. Получены
`mAP50-95=0.3707408944391919` и `mAP50=0.5258465300872381`. SHA-256 JSON с
предсказаниями:
`cda5c8c7a46d61d9c90f6292001eea190cb8f6617efe647a33dc6134dd57ccda`.

## Ограничения

Пакет привязан к указанному графу, входному тензору, контракту квантования и
исполнителю K1X. Разрешение камеры не является разрешением модели: каждый кадр
с сохранением пропорций помещается в 640x640. Надежность зависит от класса,
контраста, смаза, перекрытия, объектива, расстояния, порога и размера объекта
после letterbox. Таблицы размеров содержат измерения, а не гарантии.

Это инженерная передача, а не производственная сертификация. Stage58 не выполнял
обучение, выбор student-модели или совместное проектирование модели и исполнителя.
