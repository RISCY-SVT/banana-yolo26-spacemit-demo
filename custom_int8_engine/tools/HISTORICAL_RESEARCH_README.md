# Historical Research Tools

Stage-numbered programs and report renderers in this directory are retained only to
reproduce accepted research evidence. They are excluded from the `0.9.1` release,
the public demo, default builds, installed packages, and distribution archives.

The active Stage58 runtime uses the frozen executor C ABI and has no ONNX Runtime or
vendor execution-provider dependency. Git history is authoritative for removed
legacy demo and vendor-runtime build surfaces.
